Tasks and clients

How are their estimates split across days?
A task with a start and due date has its estimate divided across the working days (Mon-Fri) in that range, so a Tue to Thu task counts a third on each day. A task with no date range (like the weekly Extra Task) counts a fifth of its estimate every weekday. A task with only a due date counts in full on that day.

Publish a new version

Packages the extension exactly as it runs on this computer and publishes it as a GitHub release. Everyone else's extension offers them the update automatically, on the schedule set in Update notifications below (or straight away if they press Check for updates).

  1. Change the version below and press Set version & reload (it writes manifest.json in this extension's folder and restarts it).
  2. Write what changed in Release notes.
  3. Press Upload this new version. No GitHub token yet? Use Open GitHub page instead.

Update notifications

Controls when everyone's extension tells them a new version is out. Saved to your repository (update-policy.json), which every installed copy reads - so it works for all users, not just this computer. Every copy checks once a minute, so Notify everyone now reaches everyone with Chrome open within about 1-2 minutes; publishing from this panel does that for you automatically. Copies installed before this existed start following it once they update.

Client sites for everyone

These sites are added to everyone's Site monitor and monitoring is switched on (once - anyone can untick it or delete sites later, and deleted sites don't come back). Auto-detect also uses this list. It is saved to the repository encrypted with your ClickUp workspace, so only people connected to your workspace can read it. One site per line: Client name | https://site.com.

GitHub access

Needed for Upload this new version and Update notifications. Create a fine-grained token at github.com/settings/personal-access-tokens with access to this repository and permission Contents: read and write. The token is encrypted and kept on this computer only - it is never part of a release, so nobody else gets it.

Backup & restore

Move your accounts to another browser or computer without retyping them. The backup file includes each account's password and TOTP secret, so it is protected with a passphrase you choose. The passphrase is never stored - if you forget it, the file can't be opened. Keep the file somewhere safe.

Drive Sync

Sync mirrors your accounts (usernames, passwords, TOTP) and done / not-done status to your Google Drive, so a new browser or computer restores everything automatically - no need to re-enter credentials. Credentials are obfuscated in Drive (same as local storage - anyone with Drive access could recover them). Live balances and availability stay on this device and are never uploaded.

Drive sync off
Where is it saved?

In your Google Drive's hidden app data: a private area that only this extension can open. It doesn't show up as a folder in My Drive, and nobody you share Drive files with can see it. To check its size or delete it: open Google Drive settings, go to Manage apps, find this extension (it says "Hidden app data") and use Options > Delete hidden app data.

Floating tracker

A small window that stays on top of every app, showing the task you're tracking, how close it is to the estimate, and a face that goes from sad to happy as you reach it (and grumpy once you go over). Open it with ⧉ Float in the Tracking now bar, or the button below. Chrome needs one click in a small pinned tab to show it.
